# Desktop Design Assets

The SVG icons and their PNG exports come from the user-provided Figma file
`cxaBufUY2jTxJt1E50MUUj`, frames `1:2`, `12:53`, and `12:259`.
Slint renders the SVG files so icons remain sharp at different display scales.

Bundled fonts are loaded locally; the application does not fetch fonts at runtime.

- Roboto: Google Fonts, `https://github.com/google/fonts/tree/main/ofl/roboto`;
  see `Roboto-OFL.txt`.
- Roboto Slab: Google Fonts, `https://github.com/google/fonts/tree/main/apache/robotoslab`;
  see `RobotoSlab-LICENSE.txt`.
- JetBrains Mono: Google Fonts, `https://github.com/google/fonts/tree/main/ofl/jetbrainsmono`;
  see `JetBrainsMono-OFL.txt`.

Chinese text uses the platform font fallback. The QR image is generated from
the current pairing credentials at runtime, not from a design export.
